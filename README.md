# ChooseBrowser

Pick a browser for every link.

ChooseBrowser is a small macOS utility. Set it as your default browser once, and
every `http`/`https` link you click — in Mail, Slack, Notes, anywhere — opens a
compact chooser listing the browsers installed on your Mac. Pick one with a
click or <kbd>⌘1</kbd>–<kbd>⌘9</kbd>, and the link opens there.

## What it does

- Lists every installed browser automatically, with icons
- Per-site rules that can match a URL path, so one site can route to two browsers
- Opens links in a specific Chrome, Edge, Brave, Vivaldi or Chromium **profile**
- Learns which browser you prefer per site and puts it first
- Optional iCloud sync of rules across your own Macs
- No accounts, no tracking, no analytics
