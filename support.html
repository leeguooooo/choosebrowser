Support

ChooseBrowser for macOS

Report a problem or ask a question

Open an issue on the public tracker: github.com/leeguooooo/choosebrowser/issues. Include your macOS version and which browsers are installed.

Common questions

  • Links still open in my old browser. Open ChooseBrowser and click “Set as Default Browser”, or pick ChooseBrowser under System Settings › Desktop & Dock › Default web browser.
  • A browser is missing from the list. ChooseBrowser lists apps that macOS knows can open http/https links. Launch the browser once, then reopen the chooser.
  • How do I stop using it? Choose another default web browser in System Settings, then delete ChooseBrowser. Your rules live inside the app’s container and are removed with it.
